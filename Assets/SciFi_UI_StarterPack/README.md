# 🚀 Sci-Fi UI Starter Pack

A curated collection of UI assets for your sci-fi top-down shooter game.

## 📁 Folder Structure

```
SciFi_UI_StarterPack/
├── Fonts/           # Typography for UI text
├── Icons/           # Ship icons and icon packs
├── UI_Elements/     # Basic UI components
├── VFX/
│   ├── Particles/   # Particle effect textures
│   ├── Noise/       # Noise textures for effects
│   └── Gradients/   # Gradients and masks
└── Backgrounds/     # Background images
```

## 💡 Quick Tips

1. **For TextMesh Pro**: Import fonts and generate SDF atlases for crisp text at any size
2. **For UI animations**: Use gradients and masks with shaders for dissolve/reveal effects
3. **For particle systems**: Noise textures work great as custom particle textures
